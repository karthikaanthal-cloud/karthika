30-day web development learning roadmap for a beginner student aiming to get a web dev job

Duration
30 days
Daily time
3 hrs
Projects
4 builds
Goal
Web dev job
Week 1 — HTML & CSS
Week 2 — JS Deep Dive
Week 3 — React Basics
Week 4 — Portfolio & Jobs
Week 1 — Solidify the foundation
HTML structure + CSS styling — build real pages from day 1
Milestone: Build and deploy a personal webpage from scratch
Daily tasks
Day 1
HTML basics: tags, structure, semantic elements
Day 2
CSS selectors, box model, colors, fonts
Day 3
Flexbox layout — build a navbar + hero section
Day 4
CSS Grid — build a 3-column card layout
Day 5
Responsive design + media queries
Day 6
Build: personal webpage (HTML + CSS only)
Day 7
Deploy on GitHub Pages + review & polish
Resources
  • The Odin Project (free, project-based)
  • CSS Tricks — Flexbox & Grid guides
  • freeCodeCamp HTML/CSS cert
  • MDN Web Docs for reference
Project build
  • Personal webpage with bio, photo, links
  • Hosted live on GitHub Pages
  • Mobile-responsive layout
Week 2 — JavaScript deep dive
You already know some JS — now master DOM, events & async
Milestone: Build an interactive to-do app with local storage
Daily tasks
Day 8
DOM manipulation — querySelector, innerHTML, events
Day 9
Arrays, objects, ES6+ (arrow fns, destructuring, spread)
Day 10
Fetch API + async/await — call a public API
Day 11
Local Storage — persist data in the browser
Day 12
Build: interactive to-do list (add, delete, complete)
Day 13
Build: weather app using a free weather API
Day 14
Code review, refactor, push both projects to GitHub
Resources
  • javascript.info — best free JS book
  • OpenWeatherMap free API
  • Traversy Media JS crash course (YouTube)
  • 30 Days of JavaScript (GitHub)
Project builds
  • To-do list app with local storage
  • Weather app with live API data
  • Both pushed to GitHub with README
Week 3 — React fundamentals
The #1 skill employers look for — components, state, props
Milestone: Build a multi-page React app with routing
Daily tasks
Day 15
React intro — create-react-app, JSX, components
Day 16
Props + state with useState hook
Day 17
useEffect — fetch data on load, side effects
Day 18
React Router — multi-page navigation
Day 19
Tailwind CSS with React — rapid styling
Day 20
Build: movie/book search app (API + React)
Day 21
Polish, test & deploy on Vercel
Resources
  • React docs — react.dev (official, excellent)
  • Scrimba React course (free tier)
  • TMDB or OMDb free API for the project
  • Vercel for free hosting
Project build
  • Movie/book search app in React
  • Multi-page with React Router
  • Live deployed on Vercel
Week 4 — Portfolio & job prep
Put it all together, make it hirable, start applying
Milestone: Live portfolio site + resume + 5 job applications sent
Daily tasks
Day 22
Build portfolio site in React — home, projects, about, contact
Day 23
Add all 3 projects with screenshots, links, descriptions
Day 24
Polish GitHub — pinned repos, good READMEs, profile README
Day 25
Write a dev-focused resume + LinkedIn update
Day 26
Practice 10 common JS interview questions
Day 27
Practice 5 React interview questions + live coding
Day 28–30
Apply to 5+ jobs, write tailored cover notes, do mock interviews
Resources
  • Frontend Interview Handbook (free)
  • Greatfrontend.com — practice problems
  • LinkedIn Jobs + Wellfound (AngelList)
  • Resume: Reactive Resume (free, open source)
Final deliverables
  • Portfolio site live on Vercel
  • 3 projects on GitHub with READMEs
  • Resume + LinkedIn ready
  • 5 job applications submitted
After 30 days: You'll have a live portfolio, 3 real projects, a polished GitHub, and be actively applying for junior web dev roles — all built on your existing Python/JS base.
